## Flagship work

### 1. VidRango — Multi-Format Video SaaS

**[Full case study](https://mehedihasan.work/projects/vidrango/)** · **[Product](https://vidrango.com/)**

**The challenge:** One source video may require multiple formats, processing stages, metadata and separate exports for different publishing platforms.

**My implementation focus:** Full-stack product flow, upload-to-delivery states, background media processing, transcription/captions, reframing and output preparation.

**Relevant engineering:** Next.js · Node.js · PostgreSQL · Prisma · FFmpeg · APIs · operational debugging.

**What it demonstrates:** Building a coherent user experience on top of a multi-step technical pipeline, including progress, error states, testing and delivery.

**Evidence boundary:** This is a public product and a portfolio case study; production infrastructure and source code are not made public here. No fabricated subscriber, revenue or processing-performance claims.

### 2. Kinivalo — Custom Commerce & Fulfilment Operations

**[Full case study](https://mehedihasan.work/projects/kinivalo-bd/)** · **[Store](https://kinivalo.com/)**

**The challenge:** A commerce site must connect checkout with real payment statuses, delivery handoffs and day-to-day order administration.

**My implementation focus:** Custom storefront and checkout, bKash payment integration, Pathao delivery workflows, internal order handling, duplicate order protections and risk-aware checkout behavior.

**Relevant engineering:** PHP · MySQL · webhooks · payment callbacks · courier API · server operations.

**What it demonstrates:** Engineering customer-facing transactions and operational rules together—not simply installing a shopping template.

**Evidence boundary:** Public storefront and non-confidential scope are visible; private payment records and fraud controls remain protected. No unverified sales-lift claims.

### 3. Mohammadpur News — Bilingual Publishing & Newsroom Tools

**[Full case study](https://mehedihasan.work/projects/mohammadpurnews/)** · **[Bangla site](https://mohammadpurnews.com/)** · **[English edition](https://mohammadpurnews.com/english/)** · **[Newsroom digital tools](https://mohammadpurnews.com/english/tools/)**

**The challenge:** A local news publisher needed organized news presentation, two language experiences and practical utilities for preparing editorial content and publishing assets.

**My implementation focus:**
- Bengali-first, responsive newspaper layouts and English reader experience.
- **Microsoft Azure AI Translator API** integration for automated English-language content translation; this is not a claim that every translation was written manually.
- Story navigation, categories and regional/district discovery interfaces.
- Public newsroom tools: URL/text summaries, headline & SEO preview, word counting/cleanup, image-to-PDF and PDF-to-image, social/quote cards, image optimization and Bijoy–Unicode conversion.

**What it demonstrates:** Integrating editorial UX, a third-party language API, and task-focused tools within a single website.

**Client outcome:** Completed client delivery. The client has reported being fully satisfied. This is a summary of reported feedback, **not** an invented testimonial, 5-star rating or quantitative performance claim.

**Evidence boundary:** Readers can inspect the Bangla, English and newsroom tools pages. Automated translations and editorial drafts require review where appropriate.

**[Full case study](https://mehedihasan.work/projects/purepets/)** · **[Store](https://www.purepetsfood.com/)**

**The challenge:** A pet store needs useful product listings, accurate catalog organization and discoverability—not just an attractive storefront.

**My implementation focus:** WordPress/WooCommerce catalog workflows, product titles and descriptions, image/content standards, responsive shopping experience and technical/on-page SEO foundations.

**What it demonstrates:** Bridging e-commerce implementation, product-data operations and practical SEO work.

**Evidence boundary:** The website and catalog structure are public. Search Console growth, conversion lift and sales increases are **not claimed** without verified reports.
